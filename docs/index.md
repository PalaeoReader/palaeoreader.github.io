## About PalæoReader

**PalæoReader** (also PalaeoReader) is a free/open-source web-based tool that allows users to interact with previous interpretations and analyses of individual texts and add their own.

## Background

### Licensing

PalæoReader is licened under the AGPL v3 license.  This allows anyone to deploy the software for any collection in an unrestrictive way.
